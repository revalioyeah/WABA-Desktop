# Phase 1 Acceptance Checklist

## A. Window enumeration
- [ ] Open Google Play Games and launch Warung Life Simulator.
- [ ] Click Refresh in WABA.
- [ ] Confirm the game window appears in the list.
- [ ] Confirm the selected title and client dimensions are shown.

## B. Capture
- [ ] Keep the game visible and unobstructed.
- [ ] Click "Ambil satu frame".
- [ ] Confirm the preview shows the game, not a black image.
- [ ] Start live preview and verify the game clock/scene changes.
- [ ] Minimize the game and confirm capture reports an unavailable/minimized target.

## C. Manual input
- [ ] Capture a frame.
- [ ] Identify a harmless point in the game.
- [ ] Enter client-relative coordinates.
- [ ] Click "Test klik kiri".
- [ ] Read the warning and confirm only when the point is safe.
- [ ] Confirm the pointer moves and one click is received.

## D. Stability
- [ ] Run live preview for 5 minutes.
- [ ] Confirm WABA remains responsive.
- [ ] Confirm capture errors are visible in status/log.
- [ ] Confirm Stop live preview stops frame polling.

## Do not proceed to automatic order execution until A-D pass.
